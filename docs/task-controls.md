# 任务、用量与读取边界

分析任务使用 PostgreSQL 持久队列，模型调用期间不持有资料/任务行锁。Worker 使用独立 lease token、到期时间和续租线程；重启后回收过期任务，旧执行不能覆盖新代次的结果。同一空间同时最多执行一个分析任务。默认每个 Worker 两个分析执行槽位，全局最多四个实际模型 HTTP 请求。

网页可取消排队或运行中的任务。已发送给模型平台的请求可能仍产生费用；取消会阻止后续模型/工具调用及结果落库。清空空间时会移除检查点，执行中的旧任务结束后再次清理，避免结果重建。

## 默认边界

| 项目 | 默认值 |
| --- | --- |
| 访客每日分析 / OCR 任务 | 8 次 |
| 已注册账号每日分析 / OCR 任务 | 100 次 |
| 访客 / 账号每日 Token 预算 | 120,000 / 1,500,000 |
| 全局每日 Token 预算 / 任务数 | 10,000,000 / 2,000 |
| 同一 IP 每日任务 | 300 次 |
| 同一 IP 分析 / OCR 每分钟提交 | 每种 20 次（UTC 日额度之外的短窗保护） |
| 全局排队与执行中任务 / 单空间 | 100 / 2 |
| 单次任务累计模型预算 / HTTP 调用次数 | 160,000 Token / 24 次 |
| 单空间资料 / 总资料 | 20 MiB、500 份 / 512 MiB、20,000 份 |
| 执行租期 / 最多自动尝试次数 | 90 秒 / 3 次 |

可在 `.env` 覆盖 `.env.example` 中的设置。每日额度按 UTC 零点重置，网页显示当地重置时间。IP 来自直接连接地址；当前服务仅面向本地，未来反向代理接入须显式配置可信代理，不盲信客户端传入的转发头。

配额使用数据库行锁串行预留，所有 HTTP 尝试都记账，包含主分析、截图 OCR、语义重排与重试。供应商返回有效用量时按其总 Token 结算；没有用量或网络结果不确定时按保守预留结算，防止失败重试绕过预算。没有发送或明确 4xx 拒绝时释放预留。失联的预留由 Worker 定期保守结算。

真实 HTTP/队列/图/检索与本地模型协议的并发及故障实测见 [pipeline-performance.md](./pipeline-performance.md)。保留每 IP 20 次/分钟的短窗限制，因此 429 也计入压测结果；不能把成功样本的耗时当作无限到达量下的吞吐能力。Worker 崩溃后旧模型槽和未知费用预留不会立即释放，窗口与本轮观测均在报告中列明。

文本预留基于 UTF-8 字节数和额外余量，图片使用可配置预留；它是应用预算约束，不是供应商账单或精确 tokenizer。当前没有配置供应商单价，界面不展示货币费用。

导入、检索、索引重建和重试同时受空间、IP、全局频率约束，换访客 Cookie 不能绕过 IP / 全局边界。逻辑资料容量不等于数据库磁盘大小；历史回复、检查点、索引和日志的保留与容量仍需单独管理，不能据此声称磁盘占用已全面受控。

## 读取与界面

- 每 3 秒只读取 `/state/summary`：版本、任务状态、当前图节点和 Worker 心跳。后台标签页停止周期查询，切回时立即刷新。
- 版本变化才重新获取 `/state`；首屏最多 20 轮咨询，不返回资料正文。历史使用时间和 ID 组合游标，避免时间相同漏记录。
- `/items` 按类别、搜索词、状态分页，默认 40 条、最多 100 条。搜索和筛选覆盖整个空间，而非仅当前页。
- 导入文件列表仅返回元数据；点击“查看原文”才请求 `/items/{id}/content`，且再次核验空间归属。
- 运行进度来自真实 LangGraph 节点，包含执行代次校验；不能把它当作百分比或预计完成时间。

## 回归与 CI

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q --tb=short
.\.venv\Scripts\python.exe -m ruff check app scripts/worker.py tests
```

集成检查会创建随机命名 `xinyu_test_*` 数据库，拒绝复用非空测试 Redis DB，结束后仅清理它自己创建的测试库与测试键。默认 Redis DB15；可通过 `XINYU_TEST_ADMIN_URL`、`XINYU_TEST_REDIS_URL` 指向专门测试环境。不要把测试 Redis 地址指向业务 DB。

GitHub Actions 配置了 PostgreSQL / Redis 集成回归和前端 ESLint、TypeScript、构建检查，模型调用使用确定性模拟，不消耗真实 Key。确定性功能回归不能代替真实模型的回答质量评测。
